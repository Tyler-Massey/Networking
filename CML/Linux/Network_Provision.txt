CONFIGURE STATIC IP ADDRESS
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Method 1:
- CML Linux vms use legacy /network/interfaces instead of /netplan
- /etc/network/interfaces

auto eth0
iface eth0 inet static
    address [ip address]
    netmask [subnet mask]
    gateway [default gateway]

sudo /etc/init.d/networking restart

Method 2:
- /etc/netplan/cloud-init-config50.yaml
- sudo netplan apply






CONFIGURE LINUX VM AS DHCP SERVER
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Update packages
- sudo apt update
- sudo apt upgrade
- use kea dhcp package

- /etc/kea/kea-dhcp4.conf



sudo systemctl restart kea-dhcp4-server
#restarts kea-dhcp4-server, service

sudo systemctl status kea-dhcp4-server
#checks status of kea dhcp server


sudo tcpdump -i ens3 -vvv -n port 67 or port 68
# listens for dhcp traffic

sudo tail -f /var/log/apache2/access.log
# listens for apache traffic
